# SentinelFlow
Autonomous real-time security investigation demo using a 3-broker Kafka KRaft cluster, Spark Structured Streaming, a 3-node Cassandra cluster, GraphQL, and an agent service.
This project is made to be tested at a three nodes cluster with the goal of rendering it scalable and cloud native in the future. if youre using Kuberenetes convert the docker compose to Kompose file. Or you could run it in an ansible setup.
